# 🛠 Hetzner Unified Ops Tool

> Багатофункціональний інструмент (Tool) для ШІ-агента, який інкапсулює всю логіку управління життєвим циклом інфраструктури (Day-2 Operations).

## 📋 Опис сервісу

Агент використовує цей інструмент, коли користувач хоче змінити існуючу інфраструктуру. Завдяки парсеру намірів (Intent Routing), інструмент розуміє команди управління живленням (Reboot, Power Off/On), операції з бекапами (Create/Delete/List Snapshot), горизонтальне масштабування (Change Type) та повне знищення ресурсів (Delete Server). 

Особливістю інструменту є виконання складних багатоетапних дій. Наприклад, зміна тарифного плану вимагає зупинки сервера ➔ зміни типу ➔ очікування ➔ запуску. Інструмент робить це автоматично і повертає агенту фінальний результат. При видаленні сервера інструмент також очищає DNS-записи в Cloudflare та видаляє сервер з БД n8n.

## 🛠 Ключові ноди
* **`[API] Fetch Compute Inventory`:** Отримує актуальний список усіх серверів для пошуку цільового ресурсу.
* **`Script: Resource Identity Resolver`:** Складний скрипт, який "вгадує" сервер за ID, IP або назвою, та визначає тип команди (action).
* **`Route: Execute Task Logic` (Switch):** Маршрутизатор операцій.
* **`[API] Post Power Reboot / Shutdown / Startup`:** HTTP-запити до Hetzner Cloud API для зміни стану живлення.
* **`[API] Terminate Compute Instance` & `[API] Purge Host Record`:** Комплексне видалення ВМ, очищення DNS у Cloudflare та БД n8n.
