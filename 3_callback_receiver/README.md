# 📩 Callback Receiver (Asynchronous Event Handler)

> Слухач вебхуків, який отримує фінальні сигнали від нових серверів та надсилає результати (успіх/збій) користувачу в чат.

## 📋 Опис сервісу

Оскільки розгортання сервера, компіляція Docker-контейнерів та міграція баз даних CVAT займає 10-15 хвилин, основний n8n воркфлоу не може чекати так довго (таймаут). 

Тому реалізовано асинхронний патерн: Cloud-Init скрипт на сервері самостійно відправляє POST-запит на цей Callback-приймач по завершенню роботи (або у разі падіння скрипта). Отримавши сигнал `success`, сервіс оновлює статус у базі даних на `Active` і надсилає користувачеві в Google Chat красиву картку з IP, URL, логінами та паролями. У разі `failed` — надсилає сповіщення про збій.

## 🛠 Ключові ноди
* **`[Webhook] Signal Listener`:** Чекає JSON-пайлоади від віддалених серверів.
* **`Check: Deployment Verdict` (If):** Розділяє логіку на гілки успішного та неуспішного деплою.
* **`[DB] Mark Project Active` (Data Table):** Оновлює інвентарну базу даних.
* **`[API] Dispatch Credentials Card`:** Формує та відправляє повідомлення у Google Chat API із чутливими даними.
