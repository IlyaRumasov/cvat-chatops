# 🧠 ChatOps Agent Orchestrator

> Вхідна точка екосистеми. Розумний ШІ-агент, що приймає команди з Google Chat, управляє контекстом діалогу та делегує задачі на суб-процеси.

## 📋 Опис сервісу

Цей воркфлоу слугує "мозком" усієї операції. Він приймає повідомлення через вебхуки Google Chat, завантажує попередній контекст розмови з бази даних PostgreSQL (щоб пам'ятати, про що йшла мова раніше) та вирішує, що робити з користувачем.

Якщо користувач хоче створити новий сервер (Deploy), агент використовує жорсткі системні правила (System Prompt), щоб зібрати всі 5 необхідних параметрів перед запуском. Як тільки параметри зібрані, генеруються безпечні паролі, і задача передається на воркфлоу `2. Deploy Backend` через ноду `Execute Workflow`. Якщо запит стосується існуючого сервера — агент викликає інструмент `Hetzner Unified`.

## 🛠 Ключові ноди
* **`[Webhook] Inbound Chat Listener`:** Приймає події з Google Chat.
* **`[Mem] Load Persistent Memory` (Postgres):** Зберігає історію розмов для кожного `space_id`.
* **`[AI] Infrastructure Agent`:** LLM (через OpenRouter або нативний Gemini), що розуміє наміри користувача.
* **`Script: Security Credential Generator`:** Генерує криптографічно стійкі паролі для Root та CVAT Superuser.
* **`[Workflow] Call Deploy Sub-process`:** Передає JSON-пейлоад в ізольований бекенд-процес.
